
# ClipKit

Free desktop software for stream clipping and video editing.

Capture moments from streams, edit vertical videos, add captions, and organize clips for TikTok, YouTube Shorts, Instagram Reels, and Snapchat.

**[Official Website](https://clipkit.net/) | [Download](https://clipkit.net/) | [Community](https://discord.gg/YybSPgPKPy)**

## Stream Viewer

Watch multiple streams in one place and capture moments from your favorite streamers.

![ClipKit Stream Viewer](https://clipkit.net/screenshots/viewer-4.webp)

## Clip Editor

Edit captured clips, create vertical videos, customize captions, and prepare videos for social media.

![ClipKit Video Editor](https://clipkit.net/screenshots/editor-caption.webp)

## About

ClipKit is designed to simplify the workflow of stream clippers, from watching streams to preparing finished videos for upload.

The application is proprietary software. This repository provides public information and links to official ClipKit resources.
